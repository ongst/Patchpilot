# 简历素材

## 项目名称

PatchPilot — 基于 LangGraph 的安全代码修复 Agent

## 三条项目描述

- 设计并实现面向 Python 与 JavaScript 仓库的代码修复 Agent，通过受限文件工具完成仓库分析、缺陷定位、结构化修复计划与统一 Diff 生成。
- 使用 LangGraph 与 SQLite checkpoint 构建可恢复工作流，在补丁应用和 Git 推送前加入双重人工审批；通过路径归一化、命令白名单和分支策略阻止越权操作。
- 构建限 CPU/内存/进程、测试阶段禁网且不注入密钥的 Docker 执行器，并建立 12 个隐藏测试任务，对补丁应用率、修复成功率、延迟和 Token 成本进行量化评测。

只有在实际运行评测后，才能把具体成功率写进简历。

## 面试追问准备

- 为什么没有使用多 Agent？
- `for + tool loop` 与 LangGraph 各负责什么？
- 为什么代码检索先采用符号图和全文搜索，而不是向量数据库？
- Docker 为什么不能被描述为绝对安全沙箱？
- 为什么补丁应用和远端推送需要两次不同的审批？
- 如何保证 `left`—不，如何保证 Agent 不会修改默认分支或读取工作区外文件？
