# PatchPilot 三分钟演示脚本

## 0:00–0:25：问题与输入

- 展示一个带确定性缺陷和测试的公开演示仓库。
- 输入仓库 URL 与 Issue，强调 Agent 没有任意 Shell 工具。

## 0:25–1:10：分析轨迹

- 展示仓库画像、基线测试、搜索和读取过的文件。
- 打开结构化 RepairPlan，说明模型决策与确定性节点的边界。

## 1:10–1:50：补丁审批

- 展示统一 Diff、文件数和行数校验。
- 修改或批准补丁，说明 LangGraph checkpoint 可以跨服务重启恢复。

## 1:50–2:30：隔离测试

- 展示禁网、无密钥、限资源容器中的测试日志。
- 如果使用失败案例，展示测试输出如何触发第二轮增量修复。

## 2:30–3:00：最终审批与结果

- 展示第二次审批、commit SHA 和 `patchpilot/run-*` 远端分支。
- 结束时展示 12 个任务的评测结果，而不是只展示成功案例。
